# Gastos del hogar

App web instalable (PWA) para registrar gastos, ingresos, tarjetas y ahorro del hogar.

- Los datos viven en una planilla de Google Sheets con un backend en Apps Script; este repositorio solo tiene la interfaz.
- Solo pueden entrar los mails autorizados en la hoja Usuarios, con inicio de sesión de Google.
- Configuración: `js/config.js` (URL del backend e ID de cliente de Google).
